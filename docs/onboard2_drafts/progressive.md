## 0. 结论先行（给综合稿的 12 条）

1. **一句话心智模型**全游戏只有一种说法（§1）：「回溯 = 撤销刚才几秒（伤也撤销），刚才的你变成残响，把刚才的动作再做一遍」。每一课的成功提示都回扣到它的三个分句之一。
2. **先看、再做、再盖章**：所有课程共用一个 `LessonRunner`（介绍 → 示范 → 练习 → 成功），示范由**真实游戏代码驱动的脚本木偶**完成（`DemoScript` + `ScriptInput`），在一个独立小世界 `Vignette` 里播放，按键图标随**观看者**当前设备动画按下。同一份脚本还用于：暂停页小循环、钟典小循环、死亡卡演示、盲测自动驾驶。
3. **阶梯按"做到了"开门，不按局数硬开**：局数只是典型值。序章只教 轻按回溯/残响/悖论；第 1 局第 2、3 间清场后的安静时刻分别教 **分岔**、**擦带**（盲测验收要求第一层内学会）；第 2–4 局每局最多两课（同步/元凶 → 卡秒/连锁 → 完美回溯/穿越）；第 5 局不再强制新课，只做掌握提示。事件型知识（紫色伤害、最后一秒、召回、多人三件套）在第一次遇到时教。
4. **"禁用"只用在两处，其余一律"不宣传"**：未学擦带前 **按住 = 轻按**（消灭清晰度报告 S1#3/#4"按了却没回血"）；未学分岔前 **按 RB 不扣时砂**，而是排队一节分岔课（好奇心加速阶梯）。同步、元凶、连锁、卡秒、完美回溯等是被动规则，照常生效，只是在被教之前不显示白话、不显示元凶标记/白菱形/倒数数字，并在局末"复盘"里点名。
5. **每个房间最多一件新东西**；安静时刻 = 清场后 1.2 s（奖励未拿也可以）或休息/商店进门 1.5 s；首领房、宝库、楼层第一间清场前永远不教。
6. **认出来就不再教**：玩家自然打出某个动作 2 次，该课降级为一行"你刚才打出了 X！"并直接打勾。
7. **排练厅从第一次进工坊就开放**：工坊西墙一道帷幕拱门（通过 `GameHooks.onHub` 放置，不改 `hub.ts`）。厅内：课程板（✓ 学会 / ★ 掌握）、投影示范的"排练幕布"、中央排练台、假人区、机关区、伊妮丝提词板。每课 = 示范 → 无限时砂练习 → 打勾 + 奖励。
8. **掌握提示**（回应"难以刻意打出特定组合"）：检测到"现在正好能打出你还没打出过的 X"的局面时，在字幕轨上提示一行（每间 ≤1、每局 ≤3、45 s 冷却、低血量与首领转阶段不提示）；局末与工坊给"今日一练"。
9. **跳过路径**：首次启动询问「第一次玩？」→ 序章 / 我会玩了；设置"引导：完整 / 精简 / 关闭"；每课可按住 [B] 0.8 s 稍后再学；可重置引导进度。多人每个座位单独记"新手"。
10. **数据不改存档结构**：教过 = `Teach`（`profile.taught[]`），做到次数 = `Stats('did.<verb>')`，推迟次数 = `Flags`，排练厅勾 = `Teach('hall.<id>' / 'star.<id>')`。`save.ts`（P6）零改动。
11. **两处必须由主程改冻结文件**：`input.ts`/`widgets.ts`（纯键盘玩家看到 L/J/I 而不是 Q；大号按键图标），`renderer.ts`（离屏 Renderer 供 Vignette 使用）。都给了退路。
12. **可测**：`?onboard=` `?lesson=` `?coach=` `?scene=rehearsal|guide|prologue` 路由、`window.__tut` 钩子、`?autoplay=onboard` 用示范脚本驾驶真实玩家，`tools/scripts/onboard_*.json` 让盲测代理只看截图就能过关；`tools/overlapcheck.cjs` 自动核对"提示从不压住玩家/敌人/预警"。

## 1. 一个心智模型（全游戏唯一说法）

### 1.1 标准句（`S('onboard','model1')` / `model2`）

| 用途 | zh | en |
|---|---|---|
| 第 1 行 | 回溯 = 撤销刚才几秒（伤也撤销） | Rewind = undo the last few seconds (damage too) |
| 第 2 行 | 刚才的你变成残响，把刚才的动作再做一遍 | The you from then becomes an Echo and does it all again |

出现位置（且只用这两行，不另写同义句）：序章第 4 步介绍卡；暂停页"回溯怎么用"页眉；排练厅课程板页眉；核心三课（轻按/残响/悖论）介绍卡第二行；死亡卡"可以撤销"一类提示的小字；钟典"回溯"条目首行。

### 1.2 三个"为什么"分句（每课成功提示必须回扣其一，图标固定）

| 编号 | 图标（`ICONS`） | zh（≤18 字） | en |
|---|---|---|---|
| W1 撤销 | `rewind` | 刚挨打？回溯就撤销 | Just got hit? Rewind undoes it |
| W2 白打 | `echo` | 残响再打一遍 · 伤害白赚 | Your Echo hits again · free damage |
| W3 爆炸 | `paradox` | 碰到自己的残响 → 爆炸 | Touch your own Echo → explosion |

进阶课的成功句格式统一为「`<结果>` · `<回扣>`」，例如分岔：「不挨打也有残响 · 想炸就炸」（回扣 W2/W3）。

### 1.3 术语首见格式（沿用 GDD §9.8 规则 1，TERMS 不改名）

所有课程卡与字幕里第一次出现的风格名，一律 `drawTermLabel(ctx, id, …)` 或在字幕里写成「风格名（白话）」：
时砂（回溯/分岔要消耗的能量）· 磁带（能倒回的最近几秒）· 旧影（3 秒前的你 · 回溯会回到这里）· 残响（过去的你 · 会重复你做过的动作）· 悖论（碰到自己的残响 → 爆炸）· 分岔（原地留下一个残响）· 同步（两次攻击同时命中 → +50%）· 元凶（刚才打伤你的敌人）· 定格伤害（回溯也拿不回的伤害）。

### 2.4 刚挨打教练 JIT Coach（草图 + 自适应规则，非协商项 5）

**何时出现**（全部满足）：引导=完整（或 `?coach=1`）；`damaged` 且 `undoable`；`p.rewindPreview().hpGain ≥ 5`；`p.canRewind().ok`；不在首领开场/转阶段（`hintsHooks.busy()`）；距上次出现 ≥ 6 s；玩家没有在 0.12 s 内自己按下回溯。

**画面**（单人）：命中顿帧后 0.12 s → `world.slowmo(0.3, 0.7)`（0.7 s 现实时间）；字幕轨顶部（§2.5）显示一行「刚挨打？按 [LB] 撤销」，按键图标每 0.33 s 按下/弹起；旧影头顶 `+N` 与血条青色斜纹同步脉冲 0.4 s（清晰度报告 S2#7）。**不画任何箭头、不在玩家头顶放字。** 字幕停留到玩家回溯或 2.5 s。
- 时砂不够时改为（每间一次）「时砂不够 {n}/{m} · 多打几下攒时砂」。

**自适应**（`coach.mode`：`full` → `fading` → `off`）：
- *自主撤销* = 一次 `restored>0` 的回溯，且按下时教练字幕**不在屏上**。计数 `Stats('coach.selfUndo')`。
- 自主撤销达 **N = 3** 次 → `fading`：只在 HP 条右侧显示 1.5 s 的小按键芯片 `[LB]`（不减速、不出字），再出现 3 次后 → `off`。
- *忘了*：同一房间内连续 3 次"可撤销 ≥10 且时砂够"的受击都没有在 3 s 内回溯 → 下一次受击回到 `full` 一次，然后回 `fading`。
- 第 2 局起默认 `off`，除非上一局"撤销率"（回溯次数 / 可撤销受击次数）< 0.15，则第 2 局开局 `fading`。
- 多人：不全局减速，改为 `world.bubbles.push({x,y,r:72,scale:0.4,dur:0.5,owner:p})`；字幕放在该玩家铭牌旁（§2.8）。

### 2.7 死亡卡（草图 + 判定器；非协商项 8）

在 `bus 'damaged'`（致命一击）与 `downed` 时，由 `onboard/deathSnap.ts` 记录快照（不改 `downed.ts`）：

```ts
interface DeathSnap { gain: number; cost: number; sand: number; reason: RewindRefusal | null;
  firstUndoableAgo: number /* 磁带上最早一个红刻痕距死亡的秒数 */; lethalFixed: boolean; anchored: boolean;
  lastSecondOffered: boolean; lastSecondPressed: boolean; killer: string /* enemy kind */ }
```

判定顺序（取第一个成立的；文案带当前设备按键图标；**只用已教过的词**）：

| # | 条件 | zh | en |
|---|---|---|---|
| D1 | `gain≥5 && reason==null && !lastSecondPressed` | 你死前 {s} 秒有 +{n} 可以拿回：按 [LB] | {s}s before the end, +{n} was yours to take back: press [LB] |
| D1b | 同上且 `lastSecondOffered` | 停摆后那 1.5 秒按 [LB] 也能自救 | In that last 1.5 s, [LB] would still have saved you |

## 3. 渐进揭示阶梯（深度）

### 3.1 五条原则

1. **一次一件**：每个房间最多出现 1 个新动词或新词（课程、认出、便条共用这 1 个额度；`Hints` 的"每房间一张"与之合并计数）。
2. **按做到开门**：每一阶的闸门 = 前置课已学会 ∧（典型局数）∧ 行为证据（`Stats('did.*')`）。局数只决定"最早"，从不单独开门。
3. **只在安静时刻教**（§3.5）；战斗中只允许刚挨打教练（核心）与掌握提示（低优先级、事后型）。
4. **好奇心加速**：玩家按了没学的键（分岔）、在暂停页点了"清场后教我"、或在死亡卡点了"去练"，对应课程排到队首。
5. **认出来就不再教**（§3.6）：自然打出 2 次 → 一行认可 + 打勾。

### 3.5 "安静时刻"与课程调度器 `LessonDirector`

`onboard/ladder.ts` 在 `GameHooks.onRoomStart` 里给每个真实房间挂一个 `LessonDirector` 实体（`world.add`），它订阅本房间的 bus（房间切换时 bus 已换新，不会泄漏）。

**安静时刻判定** `isCalm(scene)`（每 tick）：
- 单人：`scene.cleared && world.aliveEnemies.length===0 && !scene.boss && !scene.anyChoosing() && !overlayBlocking && p.state==='alive' && sinceClear ≥ 1.2 s`；或房型为 `rest`/`shop` 且进门 ≥ 1.5 s。
- 永不：`kind ∈ {boss, vault, prologue}`、楼层第一间未清场前、`hintsHooks.busy()`、`G.scenes.transitioning`、伊妮丝便条在屏、本间已用掉"新东西额度"。
- 多人：每个座位独立判定（该座位没有打开的奖励面板）。

**调度**：安静时刻成立的那一帧，`Lessons.next(ctx)` 依次检查：① 队首请求（按键/暂停页/死亡卡）→ ② 欠下的课 → ③ 阶梯中第一个 `eligible` 且本局未达上限的课 → ④ 认出（§3.6）→ ⑤ 都没有则什么也不做（安静就是奖励）。选中后 `LessonRunner.start(id, 'calm', p)`。

**推迟**：玩家走进门、按住 [B] 0.8 s、或课程开始后 25 s 未尝试 → `Flags.inc('onboard.postpone.'+id)`；推迟 2 次后不再在局内弹出，改为排练厅课程板该课挂"!"，并由掌握提示（§7）在工坊推荐。闸门型动词（分岔/擦带）推迟 2 次后**自动解锁**（`Teach.mark(id+':soft')` 视作已学会，避免玩家永远用不上）。

### 3.6 认出来就不再教（Recognition）

- 对 `sync chain tick perfect pierce culprit(残响打到被标记者) recall duet` 统计自然次数 `Stats('did.<id>')`（只算真实局，不算排练厅/课程/Vignette）。
- 某动词在被教之前自然次数 ≥ 2 → 下一个安静时刻**不开课**，改为字幕认可 3.0 s（优先级 50）：「你刚才打出了 **同步**！」+ 第二行该词白话；并 `Teach.mark(id)`、排练厅 ✓、+3 碎片（§6.7）。
- 自然次数 = 1 且该课尚未到闸门：不提前教，但局末复盘列出（§7.4）。

  practice: PracticeSpec;               // do

}

  setup(ctx: LessonCtx): void;          // spawn props relative to the hand (calm) or to the stage (hall)

  complete(id: LessonId, p: Player, how: 'lesson' | 'recognised' | 'soft' | 'skip'): void;  // Teach.mark + reward + Hall ✓

};
// onboard/mastery.ts
export const Mastery: { did(verb: string, p: Player): void; count(verb: string): number; runCount(run: Run, verb: string): number };

### 5.2 核心三课（序章与排练厅共用；局内只在"欠课"时出现）

**`tap` 回溯：撤销伤害**

| 项 | 内容 |
|---|---|
| 介绍卡 | ① 回溯（撤销刚才几秒）② 何时：刚挨打的时候 ③ 为什么：伤也一起撤销 / "When: right after a hit · Why: the damage is undone too" |
| 示范 `demo.tap`（5.0 s） | 0.0 木偶向右走 1.0 s，旧影拖在后面；1.2 木偶被拳击中 −12，旧影头顶出现「+12」，血条青色斜纹出现；1.6 慢放 0.3×，脚本字幕「按 [LB] 撤销」；2.0 轻按回溯（按键图标按下）→ 倒带涟漪，回到旧影，「+12」；2.6 正常速度；4.4 字幕「回到 3 秒前 · 生命 +12」 |
| 练习 | 木偶 `punch` 模式在玩家面前；指令「站着让它打一下 → 按 [LB]」 |
| 成功 | `rewind` ∧ `restored > 0` |
| 失败提示 | 没挨打就按 →「先让它打中你，再按」；挨打后 3 s 没按 →「旧影头上 +{n}：按 [LB] 拿回来」 |
| 成功句 | 章「撤销！」· 句「伤害撤销了：生命 +{n}」(W1) |
| 盲测看什么 | 截图里同时出现：被打的 −N、旧影 +N、青色斜纹、字幕里的按键图标；成功后血条变满 |

**`echo` 残响：再打一遍**

| 项 | 内容 |
|---|---|
| 介绍卡 | ① 残响（过去的你 · 会重复你做过的动作）② 何时：每次回溯都会留下 ③ 为什么：它的伤害白赚 |
| 示范 `demo.echo`（6.0 s） | 木偶贴着木桩砍 2 下（伤害数字旁盖小章「保留 ✓」）；走开 1 s；轻按回溯 → 回到砍的位置；残响从那里出发再砍 2 下（青色数字），字幕「刚才的你又砍了一遍」 |
| 练习 | 不回血木桩；指令分两步：「砍木桩两下」→「按 [LB] 回溯，看残响」（第 1 步在 2 次 `hit` 后自动推进） |
| 成功 | 木桩受到 `hit` 且 `info.src % 2 === 1`（残响） |
| 失败提示 | 回溯了但残响没砍到 →「回溯前要先砍到木桩：残响只会重复你做过的」 |
| 成功句 | 章「残响！」· 句「刚才的你又打了一遍 · 伤害白赚」(W2) |

**`paradox` 悖论：碰残响 → 爆炸**

| 项 | 内容 |
|---|---|
| 介绍卡 | ① 悖论（碰到自己的残响 → 爆炸）② 何时：敌人站在残响旁边时 ③ 为什么：50 伤害，还回 20 时砂 |
| 示范 `demo.paradox`（5.0 s） | 残响走到终点停住；0.4 s 后 ◆ 亮起、描边变实线、地面虚线圈；木偶走进去 → 爆炸打碎旁边的玻璃箱；字幕「◆ 亮了 → 走进去」 |
| 练习 | 玻璃箱放在玩家与其最近残响之间；若场上没有残响，第 1 步指令「先回溯一次，留下残响」 |
| 成功 | `paradox` 且玻璃箱碎 |
| 失败提示 | ◆ 未亮就碰（`echo.armed===false` 时重叠）→「等 ◆ 亮起再碰」；残响碎了没碰到 →「残响停住时最好碰：它会在终点等你一下」 |
| 成功句 | 章「悖论！」· 句「碰到残响就爆炸 · 还回 20 时砂」(W3) |

- `pullBack`：排练厅把 Ⅱ 的 HP 设为 1 并让木偶击倒他（停摆），Ⅰ 在 3 s 内到他身边按住回溯 0.4 s；成功 = `revived` 且 `source==='pullback'`。句「按住回溯：把队友拉回 3 秒前」。

- 单人时这三行显示「需要 2 名玩家」，[Y] 只看示范。

### 7.5 "今日一练"选择算法

候选 = 已学会动词 ∪ 下一阶即将解锁的动词。分数 = `3 − min(3, did)` + （上一局有机会但没打出：+1，来自检测器命中次数）+（死亡卡相关：+2）−（被忽略 3 次：−2）。取最高分；平局按阶梯顺序。出口 D：拱门名牌下「今日一练：同步」，课程板该行图钉；在厅里完成该课 ★ 额外 +2 碎片（每日一次，`RealClock` 日期）。

**本局小目标**（可砍）：R2 起出发时横幅「本局小目标：打出一次 {verb}」，完成时章「小目标完成」+1 碎片。

## 9. 文字、设备与多人规则清单（实现时逐条自查）

1. 所有课程文字走 `Text.draw` / `drawTermLabel`；正文 `body`(FP12)，次要 `small`(FP10)；**中文永不用 `tiny`**；框尺寸全部由 `Text.lineH / measure / measureWrapped / inkH` 推出，固定高度行用 `valign:'middle'`（F1 规则）。
2. 字幕与示范窗在 UI 层（`r.ui2`）；跟随世界坐标的东西（成功章）用 `r.worldUi`。
3. 按键图标一律 `drawPrompt(ctx, action, x, y, who)`，`who` = 该课玩家的 `PlayerInput`；大号图标 `drawPromptBig`（接口请求，见 (a)）。
4. **纯键盘玩家**：`DEFAULT_BINDINGS.rewind = ['KeyQ','KeyL']`，`keyFor()` 只取第 0 个 → 用 L 的人看到 Q。接口请求：`PlayerInput.lastCodeFor(action)`（`raw` 记录最后触发该动作的 code），`widgets.keyFor` 优先用它；另加启发式：20 s 没动鼠标且攻击来自 `KeyJ` → 所有提示切到 J/K/L/I 那一套。
5. 手柄：`lastDevice==='pad'` 时 LB/RB 图标，`padLayout.swapBumpers` 已处理交换。
6. 时间：全部用 `world.after()` / 课程自己的 dt 计时；禁止 `setTimeout` 与 `Math.random`（示范脚本是确定性的，Vignette 用固定种子）。
7. 中文每行 ≤ 18 字；英文每行 ≤ 44 字符，超出由 `Text.wrap` 换行并加高底板，不缩字号。
8. 颜色：教学 UI 用 C（青）表示回溯相关，B（黄铜）表示框与奖励；**示范木偶本体不用青色**（青色保留给残响/旧影），以黄铜胶片框区分示范。
9. 多人：任何课程/提示都带 `slot`；全局减速只在单人；时间气泡 r72 用于多人；谁的课只认谁的事件。

- **问卷**（每题用自己的话回答；括号内为评分要点，评分者持有）：
  1. 回溯是什么？（撤销最近几秒；受的伤也回来）
  2. 什么时候该按回溯？按哪个键？（刚挨打后；Q/LB，按截图里的设备）
  3. 残响是什么？它有什么用？（过去的你重复刚才的动作；它造成的伤害算数/白赚）
  4. 悖论怎么触发？什么时候用？（◆ 出现后走进/碰自己的残响 → 爆炸；敌人在残响旁时）
  5. 分岔是什么？怎么用它打出悖论？（不挨打、不移动生成残响，花 50 时砂；走开等它到 ◆ 再走回去碰）
  6. 擦带是什么？为什么要用？（按住回溯选择退多远，过了红刻痕松开；退得少更便宜）
  7. 时砂是什么？从哪来？（回溯/分岔消耗的能量；打人获得）
  8. 磁带是什么？红刻痕是什么？（能倒回的最近几秒；受伤时刻，退过它就撤销）
  9. 旧影是什么？（3 秒前的你，轻按回溯回到那里）
  10. 血条上的青色斜纹是什么？（回溯能拿回的生命）——**留出题**，不在本文档的课程句里直接出现，检验理解而非背诵
  11. 你什么时候应该**不**指望回溯救你？（紫色伤害/时砂不够/时间锚——答出任意一个即可；第一层未教紫色时答"时砂不够"也算）
- **通过**：11 题中 ≥ 10 题包含全部评分要点且无事实错误；第 1–6 题必须全对。另需 b.4 第 1 条为 0。
- **不通过时**：把错题对应的截图段落与 `__tut` 日志一起交回设计，按"哪一课的哪一句没被看到/看懂"修改，重跑全部盲测（换一个新代理，避免记忆）。
