## 1. 2.0 的卖点与支柱

**一句话（商店页）**：
> 「看得见的过去：轻按回到三秒前的自己，长按选择退多远。受的伤撤销，打出的伤保留——而那个被你留在原地的自己，会继续战斗。最多四根表针，同一块屏幕，同一秒。」

**回溯的一句话规则（全游戏所有 UI 都为这句话服务）**：
> **「你身后那个淡影，是 3 秒前的你。回溯 = 变回它，并拿回它当时的血量（紫色伤害除外）。你打出的伤害全部保留。被你丢下的那段时间，变成你的残响，继续替你打。」**

**支柱（2.0 版）**
1. **看得见的时间 (Visible Time)** —— 回溯的落点、回报、代价、残响的未来行动，全部在画面上可读。不读说明书也能懂。
2. **与过去并肩，与朋友同刻 (Together in the Last Second)** —— 残响、悖论、同步夹击在多人时自然放大：你可以把倒下的队友拉回三秒前。
3. **钟表般精密的手感** —— 卡秒、打断、破绽、逆弹，每一个成功都有明确的顿帧、音效、印章。
4. **一座藏满秘密的停滞之城** —— 十二响、真实时钟、隐藏楼层、会记住你死法的首领。

**命名**：主标题《秒针 2：十二响》/ SECOND HAND 2 · Twelve Chimes。版本字符串改为 12px K8 `v2.0 · 十二响`。

**叙事扩展**：大钟停在 11:59:59。午夜需要敲十二下，而钟楼只剩最后一口铃。其余十一响（十一口小铃的"钟声"）散落在塔中：裂墙后、隐藏楼层里、守护者手中、某些只有在真实午夜才出现的瞬间。集齐十一响，第十二响由你亲手敲响（真结局）。四根表针——秒针、分针、时针、闹针——是大钟的四只手，伊妮丝陆续把它们装上发条。

## 3. 回溯 2.0 (Rewind 2.0)

### 3.1 可见性：旧影、血条承诺、磁带

**旧影 (The Shadow, 三秒前的你)**
- 每帧在录像最旧一帧 `frames[0]` 处画一个空心描边的你（C1 虚线描边，35% 透明）。一根 2px 的青色"游丝"(hairspring, 40%) 沿录像路径把你和旧影连起来。
- 没有足够时砂时：旧影变为灰色点线。
- 旧影头顶浮字（世界标签，12px，进 UI 层，不受后处理影响）：
  - `+18`（C3 青）：现在回溯能拿回的血量。
  - `−6 🔒`（V3 紫 + 锁形像素图标）：窗口内受到的定格伤害，拿不回。
- 多人：自己的旧影 35%，别人的旧影 12%、无浮字。

**血条承诺 (HP Promise)** —— 替换 1.0 的灰色伤害拖尾 `hpTrail`：

| 段 | 颜色 | 含义 |
|---|---|---|
| 实心 | R3 红 | 当前生命 |
| 斜纹 | C3 青 | **回溯能拿回的部分**（= 旧影头上的数字） |
| 裂纹玻璃 | V3 紫 + 锁纹 | 被定格伤害锁定，回溯拿不回；前 3 局旁边标注"锁定 LOCKED" |

**磁带 (Tape)** —— 血条下方 90×5px：
- 30 格（每格 0.1s），1s / 2s / 3s 处有刻度。青色 = 已录制长度。
- **红刻痕**：你在这一刻受的伤（回溯越过它 = 撤销它），高度与伤害量成比例。
- **紫刻痕**：定格伤害（越过也不撤销）。
- **白菱形**：元凶命中的时刻（§3.8）。
- 在时间锚范围内：整条磁带变灰并显示锚形图标。
- 时砂以**数字**显示：`⌛⌛ 142/200`（5×7 像素数字），替换 1.0 的 4 级沙漏填充。

**拒绝时说明原因**（12px，走翻译）：`时砂不足 63/100`、`磁带太短 0.2s`、`被时间锚锁住`、`磁带烧毁 4s`。替换 1.0 的"……"。

### 3.2 轻按与擦带 (Tap & Scrub)

| | 轻按 Tap | 按住擦带 Scrub |
|---|---|---|
| 判定 | 按下后 0.18s 内松开 | 按住超过 0.18s |
| 去哪 | 旧影位置（磁带最旧一帧） | 擦带光标所在帧 |
| 光标速度 | — | 每 0.9s 现实时间后退 3s 磁带；退到最旧帧后停住 |
| 时间 | 行进 0.25s | 擦带最长 1.2s 现实时间，到时自动确认；松开即确认；按冲刺 = 免费取消 |
| 预览 | — | 光标处出现明亮的"预览你"，头顶显示 `+HP` 与 `−时砂`；从光标到现在这段路径高亮为"将成为残响"的部分，带行动图标 |
| 世界速度 | 0.15×（行进期间） | 单人：全局 0.15×；多人：**时间气泡**（见下） |

- **按下的瞬间你就无形 (intangible)**：不会受伤。完美回溯判定见 §3.9。
- **代价随距离**：`cost = clamp(round(33.4 × 回溯秒数), 25, 100)`。退 0.8s ≈ 27；退满 3s = 100。代价在擦带时实时显示。
- **时砂池**：上限 = 100 × 沙漏数（基础 2 个 = 200；主发条 +1；沙漏强化 +1）。**开局满，且每层开始补满。**
- **落地**：0.5s 无敌，以一圈缩小的钟面弧线显示；`+N` 青色数字（UI 层）；落点描白闪一下；硬朗的"咔嗒"声。
- **血量结算**：`hp = max(当前, min(maxHp, 光标帧hp − 光标帧之后受到的定格伤害))`。
- **磁带不再清空**：回溯只切掉你退过的那一段（那一段 = 残响），更早的磁带保留，可以立刻再退。
- **磁带跨房间保留**：进新房间时用 3 秒"站在入口"的帧预填，开局立刻可回溯（退回门口）。
- **画面**：取消 1.0 的全屏青色单色。改为以回溯者为圆心、半径 120px 的青色倒带涟漪（扫描线 + 轻微色差只在圈内），圈外仅在擦带期间降饱和 30%。音频闷音 0.5s（1.0 为 1.4s），擦带时每 0.5s 磁带发一声卡带"咔"。
- **时间气泡 (Time Bubble)**（多人）：回溯者周围 r72 内的实体（敌人、子弹、残响）以 0.15× 运行，气泡外的世界与队友正常运行。单人等价于半径无限。
- 设置项 `回溯模式`：轻按+长按（默认）/ 仅轻按。

### 3.4 分岔 (Fork) 与召回 (Recall)

**分岔（R / I / RB）—— 不瞬移的残响**
- 代价 50 时砂，冷却 1.0s。不移动你、不回血、不切磁带。
- 生成一个残响，重演你**最近 2.0s** 的移动与攻击：它从你 2 秒前站的位置出发，沿你的路线走到**你按下分岔的位置**。
- 终点用钟面图标标出。残响到达终点后变为"驻留残响"（§3.5），**所以悖论非常好打**：分岔 → 走开 → 等它到你脚下 → 走回去碰它。
- 它把 1.0 一个按钮的三件事拆开：回溯 = 防守（逃 + 回血）；分岔 = 进攻（制造残响）。

**召回（主发条 IV 时·中环解锁；按住分岔 0.4s）**
- 你所有已就绪的残响放弃剧本，以 420px/s 直线飞向你（宽 r8 的线形判定，24×伤害系数，穿透）。到达时触发"召回悖论"（伤害 75%，不返还时砂）。
- 弹弓连段：回溯 → 绕到敌群另一侧 → 召回 → 残响一路切穿敌群并在你身上引爆。

### 3.7 同步夹击 (Sync)

> 屏幕上的一句话：**「一起打！」**

- 两个**不同来源**在 0.25s 内命中同一个敌人 = **同步 Sync**：第二击 +50% 伤害，"嘀·嗒"节拍音 + 双环特效。
- 3 个及以上来源 = **和弦 Chord**：+100%，每多一个来源音高升一级。同一目标每 1s 最多 1 次和弦。
- 来源 = 你 / 你的残响 / 队友 / 队友的残响（`src = slot*2 + (是残响?1:0)`）。
- 有了行动珠，你能看见"残响 1.2 秒后会在骑士那里刺一下"，于是走过去和它一起刺——这是 1.0 做不到的**可规划连段**。

### 3.8 元凶 (Culprit)

- 回溯后，**在你退过的那段时间里伤害过你的敌人**，头顶出现红色钟针标记"元凶"，持续 4s，磁带上对应位置有白菱形。
- 你的残响命中元凶：**+50%**（"过去的复仇"）。
- 悖论击杀元凶：**祖父悖论 Grandfather Paradox** 印章 + 返还 100 时砂。
- 每次回溯的下一步因此一目了然：**退回去，然后让过去的自己去惩罚那个打你的家伙。**

### 3.9 完美回溯 (Perfect Rewind)

- 在你按下回溯后的 0.2s 内，本应命中你的攻击/子弹 → **完美回溯**：返还本次全部时砂；残响镀金（+50% 伤害、B5 金描边）；青金色"PERFECT"印章 + 0.06s 顿帧 + 高音铃。
- 掌握曲线：新手被打后才回溯；高手在预警最后一帧回溯。

### 3.10 最后一秒 (Last Second) —— 用死亡教会回溯

- **单人**：生命归零 → "停摆"1.5s：世界 0.2×，屏幕中央 12px 大字"回溯！"+ 按键图标。时砂 ≥ 25 时可正常回溯（照常付费），成功后回溯锁定 6s（"磁带烧毁"）。否则死亡（或触发主发条"第二根发条"复活）。
- **多人**：见 §5.5（停摆 15s，前 3s 可自救、可被队友拉回）。
- 1.0 的 `hg_lastsecond` 与零件 `old_watch` 的"死亡自动回溯"效果并入基础规则，两者改为新效果（§6.7）。

### 3.11 定格伤害与反制

- 紫色定格伤害：受到的瞬间就在血条上变成紫色锁定段；磁带上紫刻痕。
- **时间锚 Anchor**（1 层第 4 间起）：地面锁链符文圈，圈内磁带变灰、不能回溯/分岔（已存在的残响不受影响）。
- **抹除者 Eraser**（3 层起，精英词缀 1 层起可能出现）：猎杀残响。
- 定格伤害只在 3 层以后普遍出现；1–2 层只有"公证人"等少数教学敌人（§7.2）。

### 5.5 停摆与复活 (Stopped & Revive)

### 5.6 多人下的回溯、残响与悖论

## 9. 新手引导 (Onboarding)

### 9.1 序章《最后一分钟》The Last Minute（首次启动，约 4 分钟，可跳过，可在账簿/排练厅重玩）

独立场景，不再是一局游戏的第 0 间。角落里一个时钟从 11:59:00 走到 11:59:59，每完成一步前进约 7 秒；最后一步完成时钟停在 11:59:59——故事从这里开始。所有提示 12px、UI 层、满不透明度、带当前设备的按键图标。

| 步 | 教什么 | 怎么教 | 通过条件 |
|---|---|---|---|
| 1 | 移动 | 伊妮丝叫醒你，走到她身边 | 到达标记 |
| 2 | 攻击 | 一个**不回血**的假人；伤害数字 12/12/22 | 打完一次三连段 |
| 3 | 冲刺 / 卡秒 | 一个来回摆动的钟摆刀：冲刺穿过，成功时冻结一帧"TICK！冲刺开始的瞬间无敌" | 1 次卡秒 |
| 4 | 旧影与回溯 | 一个齿轮掉下砸中你（12）；时间放慢到 0.25；箭头指向旧影头上的"+12"和血条青色段："那个淡影是 3 秒前的你。**轻按 [Q]** 变回它。" | 1 次回溯 |
| 5 | 残响与同步 | 世界放慢到 0.5："刚才的你会把刚才做过的事再做一遍。**你打出的伤害，保留。**"（命中数字旁盖"保留 ✓"）铁栏后一口铃要两下同时敲响："一起打 → 同步" | 1 次同步 |
| 6 | 悖论与分岔 | 一个只有悖论能打碎的玻璃箱："◆ 出现 = 就绪，走进你的残响"（地面虚线圈预告）；再演示"**按 [R] 分岔**：残响会走到你脚下" | 1 次悖论 |
| 7 | 擦带 | 一道扫过的激光，磁带上 1 秒前有安全缝："**按住 [Q]** 选择退多远" | 1 次 ≤1.5s 擦带 |
| 8 | 紫色 | 伊妮丝扔出一道紫色光弹："有些伤口无法撤销。"演示血条锁定段；然后（且只在此时）刷出两只齿轮仔 | 清场 |

完成：回到工坊，获得 15 碎片，伊妮丝指向主发条（"把碎片拿去，给它上发条"），排练厅开放。死在序章不会重来整段，从当前步骤重试。1.0 存档玩家首次启动 2.0 时询问"体验新的序章？"。

### 9.8 名字保留，但第一次就要看懂（用户追加要求 · 发布阻断级）

> 用户原话："你的有些名称、UI、风格我理解你这样是好的，但是就是第一次玩有点难明白到底是什么。"

**规则 2 · 一次只教一件事（渐进揭示 Progressive disclosure）**

**规则 3 · 一句话目标常驻**

## 12. 文字清晰度与 2.0 呈现 (Text & Presentation)

### 12.1 文字规则（发布阻断级）

| 规则 | 内容 |
|---|---|
| 字号 | **正文/关键信息 FP12（行高 15）**：提示、教学、"将替换"、价格、便条、按键提示、门标签。**次要文字 FP10（Fusion Pixel 10px，行高 13）**：标签芯片、风味文字、HUD 标注。**FP8 只用于拉丁字母和数字**（`G.tiny`）。任何中文都不得小于 10px |
| 数字 | HUD 数字从 3×5 升为 5×7；3×5 只用于极小角标 |
| 清晰 | **UI 画在设备分辨率的覆盖画布上**：逻辑坐标仍是 640×360，字形块以整数倍 `m = round(s)` 放大（文字因此是布局尺寸的 80–133%；所有界面按实测文字尺寸排版，到 150% 都不溢出），边缘对齐设备像素。任何窗口尺寸（1366×768、125%/150% 缩放、最大化浏览器）都锐利 |
| 世界文字 | 交互提示、路牌、旧影 `+HP`、伤害数字、横幅、商店说明、慢慢的台词进入"世界标签队列"，在 UI 层按世界坐标绘制，不受泛光/色差/扭曲/颗粒影响；最低不透明度 0.7；可选 85% K0 底板 |
| 对比度 | 正文 ≥ K8，次要 ≥ K7（在 K0–K2 底上）；K4–K6 不再用于文字 |
| 修复 | 小写字母下伸部被截（g/j/p/q/y、FP12 的 `_`）；手柄 ⧉ ✥ 等缺字改为手绘图标 |
| 设置 | 文字大小 100% / 125%（面板与卡片重排；卡片宽 180 → 188/228） |
| 包体 | 构建时按实际使用字符子集化字体（fontTools），单文件版不增大 |

## 13. 风险与砍单顺序 (Risks & Cuts)

| 风险 | 对策 |
|---|---|
| 4 人 × 残响 × 行动珠导致画面混乱 | 3–4 人每人残响上限 2（全队 8）；别人的路径 40% 透明、无行动珠；别人的旧影 12%；敌弹保持品红且绘制在最上层 |
| 擦带与轻按的阈值手感 | 0.18s 可调；设置"仅轻按"；以排练厅为调参场 |
| 新名词过多（旧影、磁带、分岔、同步、元凶、连锁、节拍） | 序章只教 旧影/回溯/残响/同步/悖论/分岔/擦带/紫色；元凶、节拍、破绽、词缀只通过便条首次出现；每个房间最多出现一个新词 |
| 多人重构破坏单人 | `world.player` 保留为兼容 getter；每个基础包都要通过单人 bot 全通关回归 |
| 平衡爆炸（连锁 + 循环 + 哨兵） | 擒纵器互斥且每局一个；同步和弦每目标每秒 1 次；节拍伤害上限 +16% |
| 设备分辨率 UI 破坏离屏文字（标题标志烘焙等） | 只在上下文带缩放变换时走高分辨率路径 |
| 确定性（`Math.random`、`setTimeout`） | 基础包统一改为种子随机与 `world.after()`；每日一秒依赖于此 |
| 存档兼容 | 档案 v2，浅合并 + 退还碎片 |
| 嗒的录像存储 | 最近一次死亡 20s + 4 次各 6s，约 50KB；无数据时用通用版本 |
