# 《秒针》美术圣经 (Art Bible)

> 美术部 · 所有美术资源必须遵守本文档

## 1. 基调

**"停在最后一秒的钟表之城"**：深靛蓝的阴影，黄铜与烛光的暖色高光，铜绿的青色点缀。整体像一只在深夜里打开的旧怀表——暗、精密、温暖、略带忧伤。

关键词：**黄铜、烛光、铜绿、悬停的尘埃、精密的齿轮、凝固的雨**。

反面清单（绝对禁止）：
- ❌ 静态贴图角色（必须有逐帧动画 + 程序化次级动画）
- ❌ 一整张背景图（场景必须由瓦片、道具、光照、粒子、环境动画组成）
- ❌ 渐变色 UI、圆角卡片、系统字体、Emoji、通用图标
- ❌ 模糊的缩放（必须整数倍最近邻放大）
- ❌ 调色板之外的颜色（光照除外）

## 3. 调色板

主调色板约 60 色，全部为**色相偏移的色阶**（阴影偏紫/偏蓝，高光偏黄），定义于 `src/art/palette.ts`。

| 色阶 | 用途 |
|---|---|
| K 夜靛（11 阶） | 阴影、描边（K0 为全局描边色）、石材、UI 底色 |
| B 黄铜（7 阶） | 齿轮、钟表零件、UI 边框、金币 |
| R 锈红（5 阶） | 主角围巾、血量、危险 |
| O 余烬（5 阶） | 火焰、烛光、灼烧 |
| T 铜绿（6 阶） | 第 1、2 层环境，锈蚀铜件 |
| C 残响青（5 阶） | **专属**：残响、回溯、时砂。环境中禁止大面积使用青色，保证残响永远醒目 |
| G 叶绿（5 阶） | 植物 |
| V 定格紫（5 阶） | 定格伤害、魔法、第 4 层星空 |
| M 品红（4 阶） | **专属**：敌方子弹 |
| U 夜蓝（5 阶） | 水、夜空 |
| S 沙（5 阶） | 第 3 层 |

### 可读性铁律
1. **玩家** = 奶白瓷 + 红围巾 + 黄铜。任何背景都不能抢主角。
2. **残响** = 青色半透明 + 加色发光。
3. **敌方子弹** = 品红/橙色亮芯 + K0 深描边 + 发光。
4. **预警** = 红色半透明地面区域，从细线 → 填满，然后闪白。
5. **环境**饱和度与明度整体低于角色一档。

## 4. 光照

- 每层有环境光颜色（第 1 层：深青灰；第 2 层：月光蓝绿；第 3 层：暖沙褐；第 4 层：星夜紫）。
- 动态点光源：火把、蒸汽灯、子弹、残响、主角的心灯（半径小的暖光，保证玩家周围永远可见）。
- 光照图以**乘法**合成到场景，然后高亮物体（子弹、火花、残响）以**加法**叠加；最终整屏做轻微泛光（Bloom）。
- 后期：暗角、极轻微颗粒、按楼层的色彩分级；回溯时去色 + 色差 + 扫描线扭曲。

## 5. 动画原则

1. **预备动作**：敌人每个攻击至少 0.35 秒前摇，伴随姿态变化 + 闪烁。
2. **挤压与拉伸**：起跳、落地、冲刺、受击都有形变。
3. **跟随动作**：主角围巾为 Verlet 物理链；Boss 的装饰件有延迟摆动。
4. **打击感三件套**：命中顿帧（40–90ms）、受击闪白（2 帧）、震屏（按伤害缩放，有上限，可在设置中关闭）。
5. **刀光（Smear）**：近战攻击使用程序化的弧形刀光，颜色从亮到暗分 3 阶。
6. **环境动画**：齿轮旋转、火光闪烁、蒸汽、悬浮尘埃、凝固雨滴的微颤、水面反光。
7. **角色动画帧数**：待机 4 帧、跑步 6 帧、冲刺 2 帧 + 残影、攻击由刀光承担、受击 1 帧、死亡 = 爆碎成零件粒子。

## 6. 主角设计：滴答 Tick

- 头部：圆形**瓷白钟面**，一只单圈"眼"（表盘中心），头上的细指针会随回溯充能转动。
- 身体：深靛色短外套，黄铜纽扣。
- **红色长围巾**：Verlet 物理，跑动时向后飘，冲刺时拉直。
- 背后：**黄铜发条钥匙**，待机时缓慢转动，回溯时高速倒转。
- 武器：细长的秒针细剑（黄铜 + 红色尖端）。

## 7. UI 风格

- 框体：**深靛底 + 黄铜双线边框 + 四角铆钉/齿轮角花**，九宫格绘制，像素级手工图案。
- 回忆卡片：羊皮纸色底，守护者徽记压印在左上，稀有度用边框颜色（黄铜/青/紫/金）区分。
- 光标：一根会"滴答"跳动的小指针。
- 动画：面板弹出用 ease-out-back，选项悬停时上浮 2px + 黄铜高光扫过。
- 转场：**表盘转场**——12 道刻度扇形依次闭合，像时钟走过一圈。
- HUD：左上生命条（黄铜管 + 红色液体，受击时白色残血缓降）；生命条下方为**沙漏充能**（每格一个小沙漏，充满时翻转发光）；右上黄铜/碎片计数；左下回忆槽位图标；屏幕下方居中显示 Boss 血条。
